# Local tooling library

The distributed punch and die directories are empty. No ready-made punch or die DXF, FCStd or JSON metadata files are bundled.

Import your own compatible models and sidecars. The parametric editor is currently available in develop.

Use `punch/` and `die/` for local tool models and matching metadata. The directories are retained in Git, while their local contents are ignored. Set real segment lengths and quantities for your own stock. Existing saved projects may need replacement tooling selected.

Backgauge, clamps and machine-frame files remain separate. Geometry validation does not certify machine safety or manufacturing feasibility.
