# Security policy

The public preview on `main` is 0.1.0; the active development preview on `develop` is 0.2.0. Please include the branch, version and commit when reporting a problem. Report suspected vulnerabilities privately using GitHub's private vulnerability reporting if enabled, or contact the repository maintainer through GitHub to arrange a private report. Do not attach confidential CAD, crash dumps, paths or credentials to a public issue.

SMBS is a planning and sampled-geometry preview tool, not a certified press-brake controller or a substitute for machine-specific safety checks.
