# Task 1.0.1b-2-fix — Канонизация боковых торцов сектора гиба и валидация топологии граней

## 1. Обзор задачи и цели

В рамках задачи Task 1.0.1b-2-verify была выявлена причина неполного сшивания боковых швов в деталях `z_10_20_10_ok`, `135_ok`, `u_60deg_30deg_ok`:
- Вызов `SheetMetalBendSolid.bend_solid` использует `BRepOffsetAPI_MakeOffsetShape`, генерирующий боковые торцы цилиндрических секторов деформации как поверхности типа `Geom_BSplineSurface`.
- Алгоритм OpenCASCADE `ShapeUpgrade_UnifySameDomain` не объединяет грани типа `Geom_BSplineSurface` с аналитическими гранями `Geom_Plane`, даже если они геометрически строго компланарны.
- В эталонных моделях FreeCAD (`*.FCStd`) верстак SheetMetal генерирует составное тело без унификации, имеющее 22 грани (по 4 шва на каждый гиб), в то время как каноническая топология 2-гибочной детали насчитывает ровно 14 граней.

### Выполненные работы:
1. В `smbs_core/Geometry/sheetmetal_folder.py` реализован статический метод `_canonicalize_bend_sector(sector_shape: Part.Shape) -> Part.Shape`, преобразующий неаналитические грани сектора в аналитические `Geom_Plane` через `BRepBuilderAPI_MakeFace(wire, True)`.
2. В `smbs_core/workers/baseline/worker.py` эталон (`ref_shape`) и восстановленная деталь (`restored_shape`) приводятся к единому каноническому виду через `ShapeUpgrade_UnifySameDomain(shape, True, True, True)` перед независимым подсчётом граней.
3. В `baseline_metrics` добавлены метрики:
   - `faces_count_reference`
   - `faces_count_restored`
   - `faces_count_delta`
   - `cylindrical_faces_delta`
4. В критерий `is_pass` включено обязательное требование: `faces_count_delta == 0 and cylindrical_faces_delta == 0`. При несовпадении выставляется `baseline_status = INVALID` с диагностикой `reason_code = TOPOLOGY_MISMATCH`.
5. Все 7 фикстур прошли тестирование в штатном пайплайне: на всех достигнут `baseline_status == VALID` и $\Delta \text{faces} == 0$.
6. Пройдены все наборы unit-тестов регрессии и baseline (6/6 PASS).

## 2. Полный код метода `_canonicalize_bend_sector`

Файл: `smbs_core/Geometry/sheetmetal_folder.py`

```python
    @classmethod
    def _canonicalize_bend_sector(cls, sector_shape: Part.Shape) -> Part.Shape:
        """
        Canonicalizes non-analytical faces of a bend sector (e.g. Geom_BSplineSurface generated by
        BRepOffsetAPI_MakeOffsetShape on side end caps) into true analytical planar faces (Geom_Plane).
        Leaves Geom_Plane and Geom_Cylinder untouched.
        """
        occ_sector = cls._to_occ_shape(sector_shape)
        builder = BRep_Builder()
        new_shell = TopoDS_Shell()
        builder.MakeShell(new_shell)

        exp = TopExp_Explorer(occ_sector, TopAbs_FACE)
        while exp.More():
            f = topods.Face(exp.Current())
            surf = BRepAdaptor_Surface(f)
            st = surf.GetType()
            if st not in (GeomAbs_Plane, GeomAbs_Cylinder):
                w = breptools.OuterWire(f)
                mf = BRepBuilderAPI_MakeFace(w, True)
                if mf.IsDone() and mf.Error() == BRepBuilderAPI_FaceDone:
                    new_f = mf.Face()
                    # Align outward normal orientation with original face
                    u_mid = (surf.FirstUParameter() + surf.LastUParameter()) / 2.0
                    v_mid = (surf.FirstVParameter() + surf.LastVParameter()) / 2.0
                    props_orig = BRepLProp_SLProps(surf, u_mid, v_mid, 1, 1e-6)
                    d_orig = props_orig.Normal()
                    if f.Orientation() == TopAbs_REVERSED:
                        d_orig.Reverse()

                    nsurf = BRepAdaptor_Surface(new_f)
                    props_new = BRepLProp_SLProps(nsurf, 0.0, 0.0, 1, 1e-6)
                    d_new = props_new.Normal()
                    if new_f.Orientation() == TopAbs_REVERSED:
                        d_new.Reverse()

                    if d_orig.Dot(d_new) < 0.0:
                        new_f.Reverse()

                    builder.Add(new_shell, new_f)
                else:
                    builder.Add(new_shell, f)
            else:
                builder.Add(new_shell, f)
            exp.Next()

        new_solid = TopoDS_Solid()
        builder.MakeSolid(new_solid)
        builder.Add(new_solid, new_shell)
        return cls._to_fc_shape(new_solid)
```
